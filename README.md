# QwikBasket - Premium Farm-Fresh Delivery

QwikBasket is a high-end e-commerce platform designed for rapid, direct-from-farm grocery delivery. Built with a focus on premium aesthetics and lightning-fast user experience.

## 🚀 Key Features

- **Dual-Mode Operation**: Seamlessly toggle between **Store Mode** (Full ordering) and **Marketing/Launch Mode** (View-only with countdown).
- **Intelligent Media Management**: Fully dynamic Hero Carousels, Promo Cards, and Popups managed via the Admin Panel.
- **B2B & B2C Integration**: Specialized pricing and verification flows for business customers.
- **Smart Delivery Logistics**: Tiered delivery fees, Smart/Qwik delivery types, and automated delivery slot management.
- **Farmer Coins Loyalty**: Integrated rewards system to empower local farmers and reward loyal customers.
- **Premium UI/UX**: Built with modern aesthetics, smooth animations (Framer Motion), and responsive design.

## 🛠 Tech Stack

- **Frontend**: React.js, Tailwind CSS, Framer Motion, Lucide React.
- **Backend**: Node.js, Express, Sequelize (SQL).
- **Media**: Cloudinary integration for dynamic asset storage.
- **Payment**: Razorpay integration.

## 📁 Project Structure

```text
/
├── backend/          # Express server, Models, Controllers, and Routes
├── frontend/         # React application, Components, and Pages
└── README.md         # Project documentation
```

## 🚦 Getting Started

1. **Backend**:
   - `cd backend`
   - `npm install`
   - `npm run dev` (Ensure your `.env` is configured with DB and Cloudinary keys)

2. **Frontend**:
   - `cd frontend`
   - `npm install`
   - `npm run dev`
